WebKit pending-seek reproduction

Each trial clears both source buffers, re-appends them, seeks to a time that is not yet buffered, and then, while that seek is still pending, seeks again to a time that is buffered. The second seek should complete. A trial is counted as stalled if no seeked event arrives within five seconds while video.seeking is still true.

Each ingredient below is something the player does that a first, simpler version of this page left out, and that version did not reproduce. Start with all of them on. If that stalls, turn them off one at a time to find which ones are actually required.
